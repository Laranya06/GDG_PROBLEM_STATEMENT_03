# 🚀 BuiltSphere — Beyond Code, Beyond Boundaries

### A Modern Interactive Developer & Team Portfolio

BuiltSphere is a responsive and interactive developer portfolio platform developed as part of the **GDG Tech Community College Web Development Competition**.

It showcases individual developers, collaborative development teams, technical skills, featured projects, achievements, and learning journeys in a visually engaging and recruiter-friendly experience.

## 🌟 Key Features

- **Individual & Team Portfolio:** Seamlessly switch between an individual developer and the CodeNova development team.
- **Light & Dark Mode:** Switch between modern light and dark themes.
- **Interactive Projects:** Explore featured projects, technology stacks, and project previews.
- **Team Member Profiles:** Discover individual developers' backgrounds, experience, skills, and achievements.
- **Team Contribution Explorer:** Learn how different developers contribute to collaborative projects.
- **Recruiter Quick View:** Quickly explore developer capabilities, relevant projects, and contact information.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Cartoon Developer Avatars:** A friendly, visually engaging profile experience.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Laranya06/GDG_PROBLEM_STATEMENT_03.git
```

Navigate into the project:

```bash
cd GDG_PROBLEM_STATEMENT_03
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Some features may require environment variables or external service configuration.

## 🎯 Project Objective

BuiltSphere aims to help recruiters, collaborators, and potential clients quickly understand a developer's capabilities through an intuitive, interactive portfolio.

The platform goes beyond a traditional resume by connecting developers' skills with their projects, achievements, and team contributions.
